# E-Learning Course UI

## Project Overview
The **E-Learning Course UI** is a dynamic web application that displays courses fetched from an API (`https://fakestoreapi.com/products`) in an interactive, responsive, and user-friendly interface. Users can search, filter, view details, and enroll in courses seamlessly. The project demonstrates modern front-end development practices using **HTML, CSS, JavaScript, and jQuery**, with **AJAX** for form submissions.

## Features & Functionalities

### 1. Course Cards
- **Features**: Dynamic display of courses, responsive grid layout, hover effects.  
- **Functionalities**: Shows course image, title, price, and "View Details" button. Cards are created dynamically from API data.

### 2. Search
- **Features**: Real-time search by course title.  
- **Functionalities**: Filters courses as the user types (case-insensitive).

### 3. Category Filter
- **Features**: Dynamic dropdown populated from API.  
- **Functionalities**: Filters courses based on selected category. Works together with search.

### 4. Course Details Modal
- **Features**: Modal popup with course details, responsive design, multiple close options.  
- **Functionalities**: Displays course image, title, description, and price. Opens on "View Details" click and closes via × button or clicking outside the modal.

### 5. Enrollment Form (AJAX)
- **Features**: Form inside modal, fields for Name, Email, Course Name, AJAX submission.  
- **Functionalities**: Submits enrollment without page reload, shows success message, pre-fills course name, and resets after submission.

### 6. Dynamic Category Dropdown
- **Features**: Auto-generates categories from API.  
- **Functionalities**: Supports scalability without manual HTML updates.

### 7. Responsive UI
- **Features**: Mobile-friendly grid, adaptive modal size, hover animations.  
- **Functionalities**: Provides smooth interaction across devices.

### 8. Interactive Experience
- **Features**: Instant filtering, modal transitions, pre-filled forms.  
- **Functionalities**: Enhances user experience and engagement.

### 9. Technical Highlights
- **Features**: HTML, CSS, JavaScript, jQuery, AJAX, API integration.  
- **Functionalities**: Clean separation of structure, style, and logic. Maintains scalability and readability.

### 10. User Experience (UX)
- **Features**: Immediate feedback, smooth animations, minimal page reloads.  
- **Functionalities**: Fast, intuitive, and modern interface for all users.
