\section{Background and Motivation}

One of the workhorses of modern hospital imaging is the abdominal CT scan. Tumour diagnosis, staging, surgical planning, radiotherapy target definition --- all of these processes rely at some stage on understanding precisely where each organ is located in the volume. Without that spatial context, downstream decisions --- how much dose to give, which margin to cut out, which structure to avoid --- are just educated guesses. This is a large problem: a busy radiology department can receive dozens of abdominal CTs a day, and each one ideally should result in a pixel-wise map of the organs before treatment planning can even get started.

Manual organ delineation is an extremely tedious and time-consuming process. For a single CT volume consisting of $200$--$400$ axial slices, requiring delineation of 13 structures, a trained radiologist would usually spend between one and three hours producing an accurate segmentation. When scaled across the entire scan volume of a large hospital this bottleneck becomes apparent --- leading to delays in treatment planning, inter-observer variation, and higher-value diagnostic tasks being neglected. Automated segmentation reduces this burden, turning hours of manual work into seconds of computation.

Deep convolutional architectures have radically changed the game for segmentation. The encoder--decoder framework popularised by U-Net~\cite{ronneberger2015} has been extended in many directions: by including attention mechanisms, by handling volumetric data, and by developing self-supervised pretraining algorithms. However, there remain some notable gaps. 3D approaches are computationally intensive, transformer approaches are data-hungry, and many published results still optimistically report per-slice evaluation metrics instead of per-volume metrics. This project aims to address these shortcomings specifically, through a careful implementation of a 2D Attention U-Net with a rigorous per-volume evaluation protocol.

\section{Problem Statement}

Our problem is \emph{multi-organ semantic segmentation}: for every axial CT slice, assign every pixel a label from 14 options (background plus 13 abdominal organs). Three specific difficulties make this daunting. First, class ratios are extremely skewed --- the combined foreground voxels for the pancreas and adrenal glands are under 1\%. Second, shape distributions are highly variable across patients, especially for the stomach and duodenum. Third, 2D slice-by-slice processing is necessary due to GPU memory constraints on freely available hardware.

A second caveat that only became obvious during our initial experiments is evaluation integrity. We observed that averaging Dice scores computed slice-by-slice gives misleadingly high average scores: the underlying problem is empty slices. When the prediction and the ground-truth are both all-zero, a na\"\i{}ve implementation with a smoothing term computes the Dice as 1.0. Though a handful of such slices inflates the average score for each volume, it actually obscures the true segmentation performance. We addressed this on a per-volume basis, using the protocol described in this report.

\section{Objectives}

\begin{itemize}
    \item Implement a 2D Attention U-Net with attention gates on all skip connections for
          multi-organ abdominal CT segmentation.
    \item Train and evaluate on the FLARE22 benchmark using a per-volume evaluation protocol
          consistent with the challenge's own scoring conventions.
    \item Quantify the contribution of attention gates, Test-Time Augmentation, and cosine
          learning-rate scheduling through a controlled ablation study.
    \item Show competitive Dice and HD95 results against published nnU-Net 3D baselines,
          while using only 2D processing and a single T4 GPU.
\end{itemize}
